【コースの流れ】

4,　角質ケア

正常なお肌のスキンサイクルは、28日サイクルです。年齢や生活環境によってサイクルが乱れてくるとお肌のトラブルの原因になります。乳酸3％を塗り古くなった角質と汚れを取り除き栄養の浸透を高めます。

5,　ポレーション

高分子のものは、注射でしか入りませんが、針を使わない無痛導入で、肌のトラブルにあわせてポレーション用高濃度美容液を細胞にダイレクトに導入します。悩みに合わせて選択します。（エイジングケア、美白、ニキビ・毛穴）

6,　イオン導入

プラセンタ原液、EGF, ビタミンC,カルノシン溶液をイオン導入し肌細胞活性をします。

・プラセンタ：抗炎症作用、美白作用、弾力回復作用、血行促進作用等）

・ビタミンC：肌のキメを整える、メラニン色素をコントロール、コラーゲンの生成、ニキビの原因に働きかける

・EGF：ターンオーバー促進、上皮細胞増殖因子、肉芽形成

・カルノシン：抗酸化作用、線維芽細胞活性化、ラミニンの生成

7,　ハンドマッサージ

お顔、デコルテ、首、肩をプラセンタ配合クリームで、マッサージします。経絡、経穴を刺激しリンパの流れをよくし、すっきりしたフェイスラインを作ります。

8,　引き上げ（キャビティーション）

ビタミンA（細胞の修復、皮脂分泌の正常化線維芽細胞の正常化など）、ビタミンE（活性酸素除去作用、代謝促進作用、血行促進作用）を引き上げながら導入します。

周波数２８Hz,１分刊に２８０００回の振動により温熱効果が血液、リンパの流れを促進し、細胞組織の代謝を高め、皮膚の引締めを新陳代謝を促します。

9,　パック

アルギン酸(海藻）パックで沈静、美白、収斂、保湿し肌をなめらかにします。

10,　お仕上げ

高品質10％プラセンタ入りローション、クリームでお仕上げします。

11,　お着替え

12,　ティーとアフターカウンセリング
