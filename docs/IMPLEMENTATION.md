# 制作・確認記録

2026年10月21日。ローカルのAstroプロジェクトにLPを実装。

## 実装

- 既存ロゴの水色、温かい白、ブルーグレーを軸にしたオリジナルの構成。
- サロン紹介、施術へのこだわり、メニュー概要、来店の流れ、実際の口コミ、ホームケア、FAQ、アクセス、予約案内。
- 既存HPのロゴと実際の店内写真を掲載。既存画像を参考にした生成写真3点を掲載。
- 掲載画像はWebPを使用。元の写真・生成PNG・取得HTMLはdocs配下に保存。
- メニュー・料金表、お問い合わせ、ショッピングは既存HPのそれぞれのページへ接続。
- 口コミは原文の抜粋3件。投稿時の年代・掲載日・元記事へのリンク付き。
- GSAPによる初回表示、ScrollTriggerによる章の表示と線の描画、PCの施術写真のsticky表示。
- Lenisによるスクロール同期。タッチ操作はブラウザーの標準挙動を使用。
- 動きを減らす設定に対応する分岐とCSS。初期HTMLには本文とリンクが存在。
- スマートフォンのモーダルメニュー、下部の電話・問い合わせバー、ネイティブdetailsのFAQ。
- 写真への装飾タイトル・イメージ注記なし。

## 確認

- `npm run build` 成功。
- `node scripts/verify-site.mjs` 成功。日本語設定、H1、内部アンカー、全掲載画像、既存HPへのリンク、口コミの原文、仮文章の混入を検証。
- ブラウザーでPC表示とスマートフォン表示を確認。
- CSS表示幅390pxと320pxで、横方向のはみ出しがないことを確認。
- 幅320px／高さ667pxの短い画面で、ヒーローの予約ボタンが下部固定バーの上に収まることを確認。
- スマートフォンのメニューを開き、口コミへのリンクを押してメニューが閉じることを確認。
- FAQの開閉と、ページ末尾まで進んだときの全画像の読み込みを確認。
- ブラウザーで記録されたJavaScriptエラーなし。

動きを減らす設定はコードとCSSの実装を確認。OS設定を変更しての検証は行っていない。

## 開発と管理

- 開発：`npm run dev -- --background`
- 状態：`npm run astro -- dev status`
- ログ：`npm run astro -- dev logs`
- 停止：`npm run astro -- dev stop`
- 本番ビルド：`npm run build`
- 生成HTMLの内容検証：`node scripts/verify-site.mjs`
- 画像の再最適化：`node scripts/prepare-images.mjs`

公開先の設定・既存HPの差し替えは行っていない。公開時は配信先のURLに合わせてOG画像などの絶対URLを設定する。

主要な編集箇所：`src/pages/index.astro`、`src/styles/brand.css`、`src/scripts/site.ts`。店舗情報・リンク・口コミは`src/data/salon.ts`で管理。
